# What is a Protocol?

A **Protocol** is a set of **rules** that allows computers and devices to communicate with each other over a network or the Internet.

**Simple Definition:**
> **A protocol is a set of rules that tells computers how to send and receive data.**

**Example:**
When you open a website, your browser and the web server use **HTTP** or **HTTPS** to communicate.

---

# Why Are Protocols Used?

Protocols are used to:

- Transfer data between computers
- Access websites
- Send and receive emails
- Transfer files
- Connect devices on a network
- Ensure secure communication

---

# Types of Internet Protocols

## 1. HTTP (HyperText Transfer Protocol)

- Used to load websites
- Transfers web pages between browser and server
- Not secure

**Example:**
```
http://example.com
```

---

## 2. HTTPS (HyperText Transfer Protocol Secure)

- Secure version of HTTP
- Encrypts data
- Used by banking and shopping websites

**Example:**
```
https://example.com
```

---

## 3. FTP (File Transfer Protocol)

- Used to upload and download files
- Commonly used by web developers

**Example:**
Uploading website files to a web server.

---

## 4. SFTP (Secure File Transfer Protocol)

- Secure version of file transfer
- Encrypts transferred files

**Example:**
Securely uploading website files.

---

## 5. SMTP (Simple Mail Transfer Protocol)

- Used to send emails

**Example:**
Sending an email from Gmail.

---

## 6. POP3 (Post Office Protocol Version 3)

- Downloads emails from a mail server
- Emails are usually stored on the user's device

**Example:**
Receiving emails in an email application.

---

## 7. IMAP (Internet Message Access Protocol)

- Accesses emails directly from the mail server
- Keeps emails synchronized across multiple devices

**Example:**
Reading the same email on a phone and laptop.

---

## 8. DNS (Domain Name System)

- Converts domain names into IP addresses

**Example:**
```
www.google.com → 142.250.xxx.xxx
```

---

## 9. TCP (Transmission Control Protocol)

- Ensures data is delivered correctly
- Reliable communication

**Example:**
Downloading a file without missing data.

---

## 10. IP (Internet Protocol)

- Provides addresses to devices
- Routes data to the correct destination

**Example:**
Every computer connected to the Internet has an IP address.

---

## 11. UDP (User Datagram Protocol)

- Sends data quickly
- Does not check if every packet arrives

**Example:**
Online gaming and live video streaming.

---

## 12. DHCP (Dynamic Host Configuration Protocol)

- Automatically assigns IP addresses to devices

**Example:**
Your Wi-Fi router gives your laptop an IP address.

---

## 13. SSH (Secure Shell)

- Securely connects to remote computers
- Used by system administrators and developers

**Example:**
Managing a Linux server remotely.

---

## 14. Telnet

- Used to access remote computers
- Not secure
- Mostly replaced by SSH

---

| FTP | File Transfer Protocol | Transfer files |

| SMTP | Simple Mail Transfer Protocol | Send emails |

| TCP | Transmission Control Protocol | Reliable data transfer |

| DHCP | Dynamic Host Configuration Protocol | Assign IP addresses |
| SSH | Secure Shell | Secure remote login |
| Telnet | Telecommunication Network | Remote login (not secure) |

| Browse Google | DNS + HTTP/HTTPS |

| Remote server management | SSH |

- Enable communication between devices
- Ensure data is transferred correctly
- Improve network security
- Support email and file transfer
- Help access websites
- Make Internet communication reliable
