# What is a URL?

A **URL (Uniform Resource Locator)** is the **address of a web page or resource on the Internet**. It tells the web browser where to find a website, image, video, or file.

**Simple Definition:**
> A URL is the address of a website or web page on the Internet.

**Example:**
```
https://www.google.com
```

---

# Parts of a URL

Example URL:
```
https://www.example.com/products/mobile.html
```

| Part | Meaning | Example |
|------|---------|---------|
| Protocol | How the browser communicates | `https://` |
| Domain Name | Website name | `www.example.com` |
| Path | Location of the page/file | `/products/mobile.html` |

---

# Types of URL

## 1. Absolute URL

An **Absolute URL** contains the complete web address, including the protocol and domain name.

**Example:**
```
https://www.google.com/search
```

**Used for:**
- External websites
- Links to other domains

---

## 2. Relative URL

A **Relative URL** contains only the path to a file or page. It does not include the domain name.

**Example:**
```
about.html
```

or

```
images/logo.png
```

**Used for:**
- Pages within the same website

---

## 3. Static URL

A **Static URL** does not change. It always points to the same web page.

**Example:**
```
https://example.com/about.html
```

**Used for:**
- About Us page
- Contact page
- Privacy Policy page

---

## 4. Dynamic URL

A **Dynamic URL** is generated automatically and may contain parameters.

**Example:**
```
https://example.com/product?id=101
```

**Used for:**
- Shopping websites
- Search results
- User profiles

---

## 5. HTTP URL

Uses the **HTTP (HyperText Transfer Protocol)** protocol.

**Example:**
```
http://example.com
```

**Note:**
- Not encrypted
- Less secure

---

## 6. HTTPS URL

Uses the **HTTPS (HyperText Transfer Protocol Secure)** protocol.

**Example:**
```
https://example.com
```

**Benefits:**
- Secure connection
- Protects user data
- Used by most modern websites

---

## 7. FTP URL

Uses the **File Transfer Protocol (FTP)** to transfer files.

**Example:**
```
ftp://ftp.example.com/files
```

**Used for:**
- Uploading files
- Downloading files

---

## 8. Mailto URL

Opens the default email application to send an email.

**Example:**
```
mailto:info@example.com
```

**Used for:**
- Contact links
- Email support

---

# URL Types Comparison Table

| URL Type | Description | Example |
|----------|-------------|---------|
| Absolute URL | Complete web address | `https://www.google.com` |
| Relative URL | Address within the same website | `about.html` |
| Static URL | Fixed URL | `https://example.com/about.html` |
| Dynamic URL | URL with parameters | `https://example.com/product?id=101` |
| HTTP URL | Non-secure URL | `http://example.com` |
| HTTPS URL | Secure URL | `https://example.com` |
| FTP URL | File transfer URL | `ftp://ftp.example.com/files` |
| Mailto URL | Opens email application | `mailto:info@example.com` |
