# What is a Web Server?

A **Web Server** is a computer or software that stores websites and delivers web pages to users when they request them through a web browser.

**Simple Definition:**

A web server is software or a computer that stores website files and sends them to users through the Internet.

**Example:**
When you visit **www.google.com**, the web server sends Google's web pages to your browser.

---

# How Does a Web Server Work?

1. The user enters a website address (URL) in a web browser.
2. The browser sends a request to the web server.
3. The web server finds the requested web page.
4. The web server sends the web page back to the browser.
5. The browser displays the website.

---

# Types of Web Servers

## 1. Apache HTTP Server
- Developed by: Apache Software Foundation
- One of the most popular web servers
- Free and open-source
- Works on Windows, Linux, and macOS

**Example:** Apache HTTP Server

---

## 2. Nginx
- Developed by: Igor Sysoev
- Very fast and lightweight
- Handles many users at the same time
- Commonly used for high-traffic websites

**Example:** Nginx

---

## 3. Microsoft Internet Information Services (IIS)
- Developed by: Microsoft
- Runs on Windows
- Supports ASP.NET applications

**Example:** IIS

---

## 4. LiteSpeed Web Server
- Developed by: LiteSpeed Technologies
- High performance
- Faster than Apache in many cases
- Commonly used in web hosting

**Example:** LiteSpeed

---

## 5. Lighttpd
- Pronounced "Lighty"
- Lightweight and fast
- Uses less memory
- Good for small and medium websites

**Example:** Lighttpd

---

## 6. Caddy
- Open-source web server
- Automatically provides HTTPS
- Easy to configure

**Example:** Caddy

---

## 7. Apache Tomcat
- Developed by: Apache Software Foundation
- Used for Java web applications
- Supports Java Servlets and JSP

**Example:** Apache Tomcat

---

## 8. Node.js Server
- Uses JavaScript on the server
- Suitable for real-time applications
- Often used for chat applications and APIs

**Example:** Node.js
