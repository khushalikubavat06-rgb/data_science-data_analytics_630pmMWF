# What is a Browser?

A **browser** (or **web browser**) is a software application that helps you open, view, and use websites on the internet.

**Simple Definition:**

 A browser is a software program used to access and view websites on the Internet.

**Example:**
When you type **www.google.com** into a browser, it opens the Google website.

---

# Types of Web Browsers

## 1. Google Chrome

- Developed by: Google
- Fast and easy to use
- Most popular web browser

**Example:** Google Chrome

---

## 2. Mozilla Firefox
- Developed by: Mozilla
- Secure and open-source
- Good for privacy

**Example:** Mozilla Firefox

---

## 3. Microsoft Edge
- Developed by: Microsoft
- Default browser in Windows
- Fast and secure

**Example:** Microsoft Edge

---

## 4. Apple Safari
- Developed by: Apple
- Available on Mac, iPhone, and iPad
- Optimized for Apple devices

**Example:** Safari

---

## 5. Opera
- Developed by: Opera Software
- Built-in VPN
- Built-in ad blocker

**Example:** Opera

---

## 6. Brave
- Developed by: Brave Software
- Blocks ads and trackers
- Focuses on privacy

**Example:** Brave

---

## 7. Vivaldi
- Developed by: Vivaldi Technologies
- Highly customizable
- Suitable for advanced users

**Example:** Vivaldi

---

## 8. Tor Browser
- Developed by: The Tor Project
- Provides anonymous browsing
- Strong privacy protection

**Example:** Tor Browser

---

## 9. Internet Explorer (Old Browser)
- Developed by: Microsoft
- Older web browser
- Replaced by Microsoft Edge

**Example:** Internet Explorer

---

## 10. UC Browser
- Developed by: UCWeb
- Popular on mobile devices
- Includes data-saving features

**Example:** UC Browser

# Uses of a Browser

- Open websites
- Search information on the Internet
- Watch videos
- Send and receive emails
- Download and upload files
- Shop online
- Use online applications
- Play online games

---

# Real-Life Example

Suppose you want to:
- Search for information → Use **Google Chrome** or **Firefox**
- Watch YouTube → Open it in a browser
- Check Gmail → Open it in a browser
- Shop online → Open Amazon or Flipkart in a browser
