# what is software ?

definition :

        software is a set of instruction that tells computer hardware exactly what to do.
Software translates human thoughts into a digital language (1s and 0s) that electronic chips can understand.

# Types of softwere

There are four types of softwere :

1. System Software

Controls the computer.
Manages hardware like the CPU, memory, keyboard, and screen.

**Examples**

1. Windows
2. macOS
3. Linux
4. Android

2. Application Software

Used to perform specific tasks.

**Examples**

1. Microsoft Word – Write documents
2. Microsoft Excel – Create spreadsheets
3. Google Chrome – Browse the internet
5. WhatsApp – Chat with friends
6. VLC Media Player – Play videos and music

3. Utility Software

Improves and protects your computer.

**Examples**

1. Windows Defender – Antivirus
2. CCleaner – Cleans unnecessary files
3. WinRAR – Compresses files
4. Disk Cleanup – Frees up storage

4. Programming Software

Helps developers write and test programs.

**Examples**

1. Visual Studio Code
2. Eclipse
3. PyCharm
4. GCC Compiler

5. Driver Software

Connects the computer with hardware devices.

**Examples**

1. Printer Driver
2. Graphics Driver (NVIDIA, AMD)
3. Audio Driver
4. Wi-Fi Driver

6. Firmware

Software permanently stored inside electronic devices.

**Examples**

1. BIOS/UEFI in a computer
2. Router Firmware
3. Smart TV Firmware
4. Easy Trick to Remember
5. System Software → Runs the computer.
6. Application Software → Helps users do work.
7. Utility Software → Maintains and protects the computer.
8. Programming Software → Creates new software.
9. Driver Software → Connects hardware to the computer.
10. Firmware → Built into hardware devices.
