# Khushali Kubavat — Premium Data Analytics Portfolio Website

A modern, high-end, responsive personal portfolio website built for **Khushali Kubavat**, a professional **Data Analyst with 5 years of experience**.

---

## 🚀 Features & Highlights

- **Visual Design & Aesthetics**: Deep navy background (`#07111F`, `#0B1F33`), electric blue (`#2563EB`), cyan (`#06B6D4`), and purple (`#7C3AED`) gradients, backdrop-blur glassmorphism, animated data grid pattern overlay.
- **Theme Toggle**: Switch between **Dark Mode** (default) and **Light Mode** with `localStorage` persistence.
- **Interactive Analytics Dashboard**: Live Chart.js interactive growth & accuracy trend chart embedded in the hero section.
- **Sticky Glass Navigation Bar**: Blur effect on scroll, active link highlighting using `IntersectionObserver`, and a **mobile right-side slide-in drawer menu** with backdrop overlay.
- **7-Category Tools & Technologies**: Skill cards featuring animated progress bars triggered on viewport scroll.
- **Interactive Project Showcase**: Filterable project cards (All, Power BI, Python, SQL, Excel) with tech pills, key results metrics, live demo/GitHub links, and an interactive **Case Study Modal**.
- **Interactive Data Workflow**: 6-phase pipeline visualization (`Collect` → `Clean` → `Explore` → `Analyze` → `Visualize` → `Decision`).
- **Achievements Counter**: Smooth count-up stat counters (`5+ Yrs`, `50+ Projects`, `30+ Dashboards`, `100K+ Rows Analyzed`, `15+ Tools`).
- **Contact Form & Floating CTAs**: Form with client-side validation & toast alert messages, plus fixed bottom-right **WhatsApp** (`+91 8160047807`) and **Call** (`+91 8160047807`) floating action buttons.

## 🛠️ Technology Stack

- **HTML5** (Semantic structure & accessible ARIA labels)
- **Tailwind CSS v4** (Utility class styling & layout)
- **Vanilla JavaScript** (Theme management, observers, modals, DOM interaction)
- **Chart.js** (Interactive data visualization graphs)
- **AOS (Animate On Scroll)** (Viewport scroll animations)
- **FontAwesome 6** (Vector icons)
- **Google Fonts** (Inter, Poppins, Space Grotesk)

## 💻 How to Run Locally

1. Clone or download the repository folder.
2. Open `index.html` directly in any modern Web Browser (Chrome, Edge, Firefox, Safari).
3. Alternatively, serve via VS Code Live Server or python HTTP server:
   ```bash
   python -m http.server 8000
   ```
4. Access `http://localhost:8000` in your web browser.
