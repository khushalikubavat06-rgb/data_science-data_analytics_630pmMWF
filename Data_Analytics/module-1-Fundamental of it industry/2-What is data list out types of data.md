What is Data?

Data is a collection of facts, numbers, words, images, sounds, or symbols that can be stored and processed by a computer.

Simple definition:

Data is raw information that has not yet been organized or analyzed.

**Example**

Name: Khushali
Age: 20
Marks: 85
City: Rajkot

These are all examples of data.

Types of Data 

1. Numeric Data (Numbers)

This data contains only numbers.

**Examples**

Age: 20
Salary: ₹25,000
Temperature: 32°C
Marks: 85

2. Text (Character) Data

This data contains letters, words, or sentences.

**Examples**

Name: Khushali
Address: Rajkot
Email: khushali@example.com

3. Boolean Data (True/False)

This data has only two possible values.

**Examples**

Yes / No
True / False
On / Off

**Example**

Student Passed: True
Wi-Fi Connected: Yes

4. Date and Time Data

This data stores dates and times.

**Examples**

Date: 30-07-2026
Time: 4:30 PM
Birthday: 30-10-2006

5. Image Data

This data contains pictures or photos.

**Examples**

Passport photo
Family photo
Company logo

6. Audio Data

This data contains sound or music.

**Examples**

MP3 songs
Voice recordings
Podcasts

7. Video Data

This data contains moving pictures with sound.

**Examples**

Movies
YouTube videos
CCTV recordings
